📘 Projeto: Lista de Nomes com Boas-Vindas
📋 Descrição
Este é um projeto simples em JavaScript que coleta nomes digitados pelo usuário, exibe uma lista numerada e mostra mensagens de boas-vindas personalizadas para cada nome.

🛠️ Funcionalidades
Coleta nomes via prompt() até o usuário digitar "sair".

Exibe os nomes com numeração usando um loop for.

Mostra uma mensagem de boas-vindas para cada nome usando for...of.

📌 Tecnologias Utilizadas
JavaScript (puro)

Executado em navegador (HTML básico)

🧠 Como Funciona
O usuário digita nomes em janelinhas prompt().

Quando digitar "sair", o programa para de pedir nomes.

O console mostra:

A lista numerada de nomes

Uma mensagem como: Bem-vindo(a), [Nome]!

▶️ Como Executar
Crie um arquivo .html e cole o código JavaScript dentro de uma <script></script>.

Abra o arquivo HTML no navegador.

Veja os resultados no console (pressione F12 para abrir).

👶 Nível
Iniciante / Júnior
Este projeto é ótimo para treinar laços de repetição e manipulação de arrays.
